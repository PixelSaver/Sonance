## About The Project

### Overall
Built for Hackclub Siege Week 6, I originally wanted to simulate air and play sounds to listen to them back. Turns out this was nowhere near small enough of a scope to do within a week, so I had to pivot to just a radio simulator. I didn't have enough time to be able to make all of the creepy stuff work though, so theres only a few radio stations set up. 

### What even is this?
Super simple radio simulator which plays music depending on the frequency of the tuning knob and the volume controlled by a volume knob. First time using in-game ui elements (knobs and power switch)
* Clicking power switch to begin
* Changing frequency with a knob
* Changing volume with a knob
* :( nothing else, bugs with export got me

### What do I take out of this?
Don't get caught up on one bug. Take the easy way out. STOP TRYING TO EXPORT TO WEB BECAUSE THE STUPID AUDIO FILES WONT WORK RAHHHH.

### Play 

If you'd like to build it yourself, I used Godot 4.5. I do have a pre-built web version available in the releases for windows, but if you want to build this unoptimized mess, go ahead.

1. Install Godot 4.4
2. Download and unzip the code
3. Open the file with Godot project manager
4. Go to Project > Export, add whichever platform you're on (MacOS, Windows) and then click export.
5. You're good to go!
